ANDROID VAULT • 10+ BRANDS

Android secret codes — what they mean

Android exposes engineering codes via dialer. Availability depends on manufacturer, model, firmware and dialer app. CodeVault filters destructive codes.

Device InformationDEVICE CODELOW

IMEI, IMEI2, MEID — *#06#

The most universal code. Shows device identifiers. No network call, display only. Use to match box, check dual SIM.

*#06#
  • Open Phone → Keypad → Enter *#06# → info appears instantly
  • Widely supported, reversible, no admin
DiagnosticsMANUFACTURERLOW

Battery & Usage — *#*#4636#*#*

Opens testing menu: battery health, usage stats, Wi-Fi info. On some brands blocked. Great for demo — shows voltage, temperature.

*#*#4636#*#*
  • If not working, manufacturer removed menu — explain that in presentation
  • Safe: display only
Presentation tip: Show this alongside PC powercfg /batteryreport to compare phone vs laptop battery diagnostics.

iOS VAULT • SCHEMA 2.1 • GSM/MMI AWARE

iPhone codes are small — carrier matters

Apple does not expose large engineering system like Android. Most iPhone codes are GSM/MMI carrier commands or Apple Field Test. We label availability correctly.

Device InformationDEVICELOW

IMEI / MEID / EID — *#06# and *#07#

*#06# shows IMEI on iPhone. *#07# shows legal/regulatory info (SAR) where supported. Both are display-only, widely supported.

*#06# | *#07#
Network DiagnosticsAPPLE CODELOW

Field Test Mode — *3001#12345#*

Apple's own cellular diagnostic. Shows LTE, 5G, signal, cell info. iOS version and carrier affect what you see. No network change.

*3001#12345#*
  • Open Phone → Keypad → Enter code → Tap Call if required
  • Model / iOS / carrier dependent
Call ForwardingGSM/MMIMEDIUM

Check vs Activate vs Deactivate forwarding

Pattern is consistent — learn once, apply everywhere. Check codes start with *#, activate with **, deactivate with ##.

TypeCheckActivateDeactivate
Unconditional*#21#**21*number###21#
No-Answer*#61#**61*number###61#
Busy*#67#**67*number###67#
Unreachable*#62#**62*number###62#
All##002# — cancel allCarrier response
Warning: **21*number# changes call routing. Always check first with *#21#. This can affect voicemail. Carrier_dependent — not guaranteed on every iPhone.
Caller ID & BarringCARRIERMEDIUM

Caller ID hide — #31#number and barring *#33#

Caller-ID suppression *67number and *82number are carrier-dependent, not universal iPhone. Barring uses PIN — never guess PIN. Teach students difference: Apple code vs GSM/MMI vs carrier USSD.

*#31# → check outgoing Caller-ID #31#number → hide for one call *#33# → check barring
PC VAULT • WINDOWS 10/11 • CMD / POWERSHELL / RUN

PC commands — from basics to diagnostics

CMD means Command Prompt. PowerShell commands are objects. Some need Administrator. Placeholders like <PID>, <path>, <username> must be replaced.

Command Line BasicsCMDLOW

help, ver, whoami, hostname

Start here. help lists commands. help ipconfig shows syntax. ver Windows version, whoami current user, hostname computer name. All low risk, reversible.

help help ipconfig ver whoami hostname

Internet DiagnosticsCMD / POWERSHELLLOW

ping, tracert, pathping, nslookup

Teach troubleshooting flow: ping 1.1.1.1 tests internet without DNS, ping example.com tests DNS, tracert shows hops, pathping shows packet loss, nslookup queries DNS, Test-NetConnection tests TCP port.

ping 1.1.1.1 ping example.com tracert example.com pathping example.com nslookup example.com Test-NetConnection example.com -Port 443
Flow: If ping IP works but ping hostname fails → DNS issue → use flushdns + displaydns.

System RepairCMD • ADMINMEDIUM

sfc and DISM — safe repair explanation

Do not run in presentation without permission — but explain what they do. sfc /scannow scans protected system files. DISM checks component store. Show help first.

sfc /scannow DISM /Online /Cleanup-Image /CheckHealth DISM /Online /Cleanup-Image /ScanHealth DISM /Online /Cleanup-Image /RestoreHealth
Medium risk — can take long, may need restart. Only run if you understand.

SAFETY • CODEVAULT RULES

What we include, what we exclude

To make your project safe for school presentation and professional.

AllowedLOW

Display-only codes are always safe

*#06# IMEI, *#07# regulatory, ipconfig, ping, systeminfo, Get-ComputerInfo — they show info, change nothing.

CautionMEDIUM

Carrier and network commands need warning

Call forwarding **21*number#, call barring **33*PIN#, ipconfig /release, chkdsk /f, sfc /scannow — they change routing, file system or system state. Mark as medium/high, explain reversibility, never guess barring PIN.

Always show: carrier_dependent, requires_admin, reversible true/false, warning field from JSON.
ExcludedHIGH

What CodeVault never includes

Security-bypass, Activation Lock bypass, FRP bypass, account-bypass, destructive reset without warning, legacy commands that wipe data. Your JSON notes already state this — we respect it in UI.

PRESENTATION TIPS • HOW TO IMPRESS

How to present CodeVault like a pro

1. Start with IMEI — everyone knows it

Ask audience to dial *#06# on their phone. Instant engagement. Then show same code works on Android and iPhone — then explain why Android has more codes than iPhone (manufacturer engineering menus vs Apple closed system).

2. Show carrier difference live

Dial *#21# on iPhone — show carrier response. Explain GSM/MMI pattern **21* vs ##21#. Show availability labels from your JSON: widely_supported vs carrier_dependent vs model_ios_and_carrier_dependent.

3. PC live demo — 30 seconds wow

Open CMD and run:
ipconfig /all && ping 1.1.1.1 && netsh wlan show interfaces
This shows IP, tests internet, shows Wi-Fi SSID and signal — all in one line.

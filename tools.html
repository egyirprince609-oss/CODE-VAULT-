IMEI Luhn Validator — from *#06#

Paste 15-digit IMEI shown by *#06#. We validate checksum locally using Luhn algorithm. Safe — offline, no server.

How it works: IMEI last digit is check digit. Double every second digit from right, subtract 9 if >9, sum. If sum %10==0 → valid.

Network Command Builder — ping / tracert / nslookup

Build correct Windows commands without typo. Shows difference between testing internet (IP) vs DNS (hostname).

Flow: ping 1.1.1.1 = internet OK? If fails → no internet. If IP works but ping example.com fails → DNS issue → ipconfig /flushdns
